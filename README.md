# Keerthana & Parthiban — Interactive Wedding Invitation

## Included
- `index.html`, `styles.css`, `script.js`
- `temple-wedding.png` — temple / traditional wedding illustration
- `romantic-wedding.png` — suit and lehenga romantic illustration
- `original-invitation.png` — invitation artwork uploaded by the family

All files are in the repository root. No `assets` folder is required.

## Interactive features
1. Animated ceremonial doors: tap **Open the doors** to reveal the website.
2. Play / pause music: an original gentle bell-like melody is generated in the browser after the visitor taps the music control. No external copyrighted music file is used.
3. Floating flower petals.
4. Click any gallery picture to open a large lightbox; close with the X, outside click, or Escape.
5. Smooth section navigation and a back-to-top action.

## Deploy to Vercel
1. Extract this ZIP.
2. Upload every file inside the extracted folder to the root of your GitHub repository (not the ZIP itself).
3. Keep the PNGs beside `index.html`; do not put them in a subfolder.
4. Commit changes. If Vercel is connected to GitHub, it will deploy automatically.
5. Or import the repository at https://vercel.com/new.

Vercel settings for this plain static website:
- Framework preset: Other
- Build command: leave empty
- Output directory: `.`
