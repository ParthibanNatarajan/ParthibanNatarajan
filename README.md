# Keerthana & Parthiban — Wedding Invitation

A responsive, static wedding invitation website. It uses the supplied couple photographs and the AI-generated traditional portrait.

## Preview locally
Open `index.html` in a browser.

## Deploy free on Vercel
1. Create a GitHub account if you do not already have one.
2. Create a new public or private repository, e.g. `keerthana-parthiban-wedding`.
3. Upload the contents of this folder (make sure `index.html`, `styles.css`, `script.js`, and `assets/` are at the repository root).
4. Sign in at https://vercel.com/ and choose **Add New → Project**.
5. Import the GitHub repository.
6. Framework Preset: **Other**. Build Command: leave blank. Output Directory: `.` (or leave default if Vercel detects the static site).
7. Click **Deploy**. Vercel will provide a free `*.vercel.app` URL.
8. To change the URL, open Project → Settings → Domains and edit the assigned `vercel.app` project name.

## Before publishing
- Confirm the venue and date/time details.
- The PDF gives the wedding venue as Signature Mahal, Mayiladuthurai. The reception venue is not stated in the English text, so the page currently says Mayiladuthurai only.
- Google Maps link searches for “Signature Mahal, Mayiladuthurai”; verify the exact pin before sharing.
- The complimentary names and family details are reproduced from the English page of the supplied PDF.
- This project has no watermark or third-party branding. Google Fonts are loaded from Google Fonts; a system-font fallback is provided.
